## 四、阅读顺序建议

1. 先读**需求文档**与**品种边界表**，建立策略与数据边界的认知；
2. 写取数/缓存代码时，对照 **tbpy方法参考** + **DB设计说明**；
3. 官方细节拿不准，再翻 **reference/** 交叉验证，但以自研文档为最终依据。
