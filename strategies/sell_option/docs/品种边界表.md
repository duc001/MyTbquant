# 品种边界表（权威数据 + symbol 编码规则）

> 本文件是期权卖出策略工具的**品种边界唯一权威源**：既是 47 品种的 symbol / 乘数 / 日线合约**数据表**，
> 也是各交易所 **symbol 编码格式字典**（大小写 / 横线 / 月份位数 / 后缀规律）。
> 重建时的取数加载器直接读取下方【一、边界表数据】那张 markdown 表，作为运行时唯一来源（旧 `config.py` 已删，本约定不变）；
> 表覆盖的品种以表为准，未覆盖的才回退静态拼接规则。
> 所有 symbol 样例均已用 `tbpy.get_instrument` 实测可解析为真实有效合约（验证记录见文末）。

## 二、symbol 编码规则（格式字典）

### 1. 铁律：symbol = `代码.交易所`

- **必须带交易所后缀**。裸 sec_id 一律无效：实测 `m2701` / `a2701` / `AP701` / `rb2701` 传 `get_instrument`
  都返回 `None` 且 `get_last_err='xxx 无效合约'`；补全成 `m2701.DCE` 才有效。
- **判有效性看返回对象的 `sec_name` 是否非空**，不要只看 `get_last_err`——它返回"最近一次错误"，
  成功查询**不会清空**（上一条无效合约的错误会残留）。

### 2. 交易所后缀（境内期货）

| 后缀 | 交易所 | 本表品种数 |
|---|---|---|
| `SHFE` | 上海期货交易所 | 8 |
| `DCE` | 大连商品交易所 | 19 |
| `CZCE` | 郑州商品交易所 | 17 |
| `GFEX` | 广州期货交易所 | 3 |
| `INE` | 上海国际能源交易中心 | 0（已删） |
| `CFFEX` | 中国金融期货交易所 | 0 |

### 3. 标的编码大小写

| 交易所 | 大小写 | 示例 |
|---|---|---|
| **CZCE** | **大写** | `AP` `CF` `MA` `SR` `TA` … |
| DCE / SHFE / GFEX / INE | **小写** | `a` `m` `rb` `lc` `ao` … |

### 4. 三类合约的编码格式

#### 4.1 期货月份合约

`代码 + 月份 + .交易所`，**月份位数随交易所不同**：

| 交易所 | 月份位数 | 样例 | 含义 |
|---|---|---|---|
| CZCE | **3 位** | `AP701.CZCE` | 2027 年 01 月 |
| DCE / SHFE / GFEX / INE | **4 位** | `a2701.DCE` `rb2701.SHFE` | 2027 年 01 月 |

#### 4.2 期权

`标的月份 + C/P + 行权价`，**大小写、横线、月份位数三处随交易所变化**（本表最容易踩错的地方）：

| 交易所 | 大小写 | 横线 | 月份 | 格式 | 样例 |
|---|---|---|---|---|---|
| **DCE / GFEX** | 小写 | **有** `-` | 4 位 | `月-C-行权价` | `a2611-C-5100.DCE` `lc2611-C-86000.GFEX` |
| **SHFE / INE** | 小写 | 无 | 4 位 | `月C行权价` | `rb2701C3500.SHFE` `ao2701C2600.SHFE` |
| **CZCE** | **大写** | 无 | **3 位** | `月C行权价` | `AP701C6700.CZCE` `CF611C15200.CZCE` |

解析正则：`^([A-Za-z]{1,2})(\d{3,4})-?([CP])-?(\d+)$`（实现期权 symbol 解析时使用；旧 `chain.py` 已删）。

#### 4.3 主力指数连续（**拉日线用这个**）

| 类别 | 后缀 | 样例 |
|---|---|---|
| CZCE / SHFE / GFEX 全部 | `888` | `AP888.CZCE` `rb888.SHFE` `lc888.GFEX` |
| DCE **新品种** | `888` | `cs888.DCE` `eb888.DCE` `pp888.DCE` |
| DCE **老品种** | `9888` | `a9888.DCE` `m9888.DCE` `i9888.DCE` |

实测 `sec_name` 均为"XX连续"、`delisted_date=3098-12-31`（永续），47 个全部有效。

> 主连是换月拼接的**原始未复权**序列，换月日会出现台阶假跳空。本项目日线口径为
> **后复权主连**：取数层调 `get_history_n` 时传 `flag=tbpy.QuoteFlag.RolloverBackWard`，
> 由服务端施加后复权因子抹平换月台阶（实测 m9888 后复权后 ≥3% 台阶消失，真实跳空保留）。

#### 4.4 加权指数（备选口径，**本项目当前不采用**）

若需要**天然无换月跳空**的加权指数（而非后复权主连）：DCE 老品种 `9000`、DCE 新品种 `000`、其余 `000`
（如 `a9000.DCE` / `cs000.DCE` / `rb000.SHFE`）。**注意与 4.3 的主连后缀（888/9888）区分**，两者不是同一合约。
本项目已改用 4.3 的后复权主连，本节仅作口径对照保留。

### 5. DCE 老 / 新品种分裂（重点坑）

DCE 的指数与主连后缀按"老品种 / 新品种"分裂，**无字面规律，只能查表**：

| 类别 | 品种 | 主连 | 指数 |
|---|---|---|---|
| **老品种**（10） | `a` `b` `c` `i` `j` `l` `m` `p` `v` `y` | `9888` | `9000` |
| **新品种**（9） | `cs` `eb` `eg` `jd` `jm` `lg` `lh` `pg` `pp` | `888` | `000` |

### 6. 合约乘数

- **以 `tbpy Instrument.contract_unit` 实测值为唯一权威**；本文件数据表"乘数"列已对齐实测。
- 历史修正：`jd`（鸡蛋）5→10；`bz`（纯苯）5→30、`op`（双胶纸）20→40（后两行连同 `zn` 已被删除）。
- 运行时一律取实测 `contract_unit` 为准，静态表值仅作对账告警。

### 7. 边界表列说明 & 取数对接约定

上方【一、边界表数据】那张 markdown 表（UTF-8，11 列，47 品种）：

| 列 | 含义 | 用途 |
|---|---|---|
| 标的编码 | 品种代码（含正确大小写） | 主键 |
| 品种 / 交易所编码 | 中文名 / 交易所后缀 | 拼 symbol、分组 |
| 现价 / 乘数 | 标的价 / `contract_unit` | 保证金、W/R 换算 |
| 单腿保证金万元 / 实际占用万元 | `现价×乘数×保证金率` / 再乘组合优惠(DCE·GFEX ×0.20) | 资格线（≤1.2 万/手） |
| **期货 symbol 样例** | 月份合约**格式模板** | 拼真实合约时套格式 |
| **主力指数样例** | 后复权主连合约（**真实可用**） | 直接拉日线（取数层传 flag=RolloverBackWard） |
| **期权样例 C / P** | 期权**格式模板** | 拼真实期权时套格式 |

> 取数对接约定：`期货symbol样例` / `期权样例C·P` = **格式参照**；`主力指数样例` = **直接可用的后复权日线合约**。
> 加载器按表头 `标的编码 … 期权样例P` 定位本表并逐行解析（UTF-8 纯文本）；旧 `config._load_symbol_table()` 已删，重建时按本约定实现。
